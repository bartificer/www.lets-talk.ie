<li>The <em>Checkm8</em> iOS vulnerability

<ul>
<li><strong>Summary:</strong>

<ul>
<li>An un-patchable vulnerability has been found in the bootrom in Apple SOCs from the A5 up to and including the A11, this means all iPhones from the 1Phone 4S up to an including the iPhone X are vulnerable.</li>
<li>The exploit requires the phone to be tethered to a computer via the lightning port to work, so cannot be exploited remotely</li>
<li>Exploits are not permanent, so do not survive a reboot</li>
<li>The vulnerability does not in any way affect the secure enclave, so it cannot be used to break into a locked device</li>
<li>The vulnerability does enable an un-patchable tethered jail break</li>
</ul></li>
<li><a href="https://www.imore.com/understanding-checkm8-iphone-4s-iphone-x-bootrom-exploit">Checkm8, the iPhone 4s to iPhone X bootrom exploit, explained — www.imore.com/…</a></li>
